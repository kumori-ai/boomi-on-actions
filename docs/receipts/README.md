# Receipts

One JSON file per recorded run, written by the script that made the run, on the date in its name. These are the
parts of the Boomi platform that the live demo at https://kumori.ai/demo/boomi does not run on demand, either
because each run leaves something permanent behind (Agentstudio), costs trial credits (starting a Data
Integration pipeline), or stops at an entitlement the test account does not have (Gateway, Molecule, DataHub,
Event Streams, a local Flow runtime). A blocked row's receipt holds the answer Boomi gave.

Ids, names of private objects and credentials were never written to these files; each was scanned again before
it was copied here.
